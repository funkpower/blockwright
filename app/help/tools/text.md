Writes live text in a font: a bundled face or a TheDraw font. The text stays editable on its own layer.

Click a text layer to edit it, or click anywhere else and type to start a new text layer there. Typing, Backspace, Delete, Enter and the arrows edit at the text cursor; Esc ends the edit.

- **Face**: the font. Search by name or type; ★ keeps a favourite.
- **Big style**, **Big colours**: whole-cell 8×8 lettering instead of the face, and its mIRC colours.
- **Case**, **Letter spacing**, **Line spacing**, **Align**, **Wrap**, **Colour**: how the text is set.

A change applies to the active text layer and to the next new text. While the cursor waits to start a new text layer, a change applies to that new text only.
