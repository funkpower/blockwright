Moves the active layer, and moves and resizes a reference layer. Alt+drag does the same move with any other tool.

Drag on the canvas to move the active layer: an art layer by whole cells, a reference layer by canvas pixels. On a reference layer, drag a corner handle to resize it from the opposite corner; the aspect is kept unless Shift is held. Esc drops a drag in progress. Each move or resize is one undo step. A locked or hidden layer does not move.

- **X**, **Y**, **Width**, **Height**: the active reference layer's place and size, in canvas pixels.
- **Keep aspect**: a new width or height takes the other side with it.
- **Scale**: the size against the picture's own; a new scale sizes both sides from the picture's own.
