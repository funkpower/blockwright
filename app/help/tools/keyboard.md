Types at the cell cursor in the pen's colours, the way a text editor does.

Click a cell to put the cursor there. Arrow keys, Home, End and Enter move it; Backspace and Delete clear a cell. F1 to F10 type the glyphs of the current F-key set, which the glyph bar shows.

Every other tool falls back to keyboard mode for the keys it doesn't use, so typing works with most tools active.
